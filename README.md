# Slides Align Panel

Googleスライドの整列・均等配置を効率化するChrome拡張機能です。
A simple alignment panel for Google Slides.
資料制作時に、何度も配置メニューを開く手間を減らすため、ChatGPTを活用して開発しました。

---

## 主な機能 / Features

- 左・中央・右揃え
- 上・中央・下揃え
- 水平・垂直方向の均等配置
- ページ中央への配置
- パネルのドラッグ移動
- パネルの折りたたみ

---

## インストール方法 / Installation

1. GitHubの「Code」から「Download ZIP」を選択
2. ダウンロードしたZIPファイルを解凍
3. Google Chromeで `chrome://extensions/` を開く
4. 右上の「デベロッパーモード」を有効にする
5. 「パッケージ化されていない拡張機能を読み込む」を選択
6. `manifest.json` が含まれるフォルダを指定する
7. Googleスライドを開く、またはページを再読み込みする

※ Chrome Web Storeでは未公開のため、手動でのインストールが必要です。

---

## 使用方法 / Usage

Googleスライドの編集画面に、整列パネルが表示されます。

1. 図形やテキストボックスを選択する
2. パネルから任意の配置操作を選択する
3. 配置された結果を確認する

整列には2つ以上、均等配置には3つ以上のオブジェクトの選択が必要です。

パネルはドラッグによる移動や、折りたたみが可能です。
