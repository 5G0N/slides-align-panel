#Slides Align Panel

Googleスライドの整列・均等配置を効率化するChrome拡張機能です。
資料制作時に、何度も配置メニューを開く手間を減らすため、ChatGPTを活用して開発しました。

主な機能
左・中央・右揃え
上・中央・下揃え
水平・垂直方向の均等配置
ページ中央への配置
パネルのドラッグ移動
パネルの折りたたみ

インストール方法
GitHubの「Code」から「Download ZIP」を選択
ダウンロードしたZIPファイルを解凍
Chromeで chrome://extensions/ を開く
デベロッパーモードを有効にする
「パッケージ化されていない拡張機能を読み込む」を選択
解凍したフォルダを指定する
Googleスライドを開く、または再読み込みする

使用方法
Googleスライド上で図形やテキストボックスなどを選択し、整列パネルから任意の操作を実行してください。

プライバシー・セキュリティ
外部サーバーへのデータ送信処理なし
個人情報の収集処理なし
外部API・外部ライブラリ不使用
動作対象はGoogleスライドに限定
本拡張機能は、Googleスライドの既存メニューを操作する仕組みを採用しています。

注意事項
本ツールは個人開発による試験版です。
Googleの公式製品ではありません。Googleスライドの仕様変更や利用環境によって、正常に動作しなくなる可能性があります。
重要な資料で使用する前に、複製した資料などで動作をご確認ください。
本ツールは現状有姿で提供され、動作や安全性を保証するものではありません。
