Slides Align Panel 0.2.3（試作版）

【インストール】
1. ZIPを展開する。
2. Chromeのアドレスバーに chrome://extensions/ を入力。
3. 右上の「デベロッパーモード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」で、manifest.json が入った slides-align フォルダを選択。
5. Googleスライドの編集画面を再読み込みする。

【操作】
画面右上付近にパネルが出ます。図形を2つ以上選択して整列ボタンを押します。
均等配置は3つ以上。ページ中央配置は図形を選んで操作します。
見出し部分をドラッグすると移動、−/+ で折りたたみ・展開できます。
パネルを消す場合は chrome://extensions/ で拡張機能をオフにして編集画面を再読み込み。

【確認状況】
v0.2.3：中央(縦)・中央(横)の表記に対応。対象メニューを限定し、疑似キー操作を削除。実画面は未確認。
v0.2.2：日本語メニューのアクセスキー表記（配置(a)、ページ中央に配置(c)など）を除去して照合。子メニューにも適用。パネルにバージョンを表示し、診断を改善。
v0.2.1：拡張機能のアイコンを追加。整列処理はv0.2.0と同じです。
v0.2.0：上部メニュー「配置」→「配置」「整列」「ページ中央に配置」に対応。上下・左右の中央が同名の場合は前後の項目から区別します。
ログイン済みGoogleスライド実画面での動作は未確認です。
Googleスライドの既存メニューを合成マウスイベントで操作するため、実画面の実装、言語、UI変更により動かない可能性があります。パネルの「操作を送信」は実際の整列成功を保証しません。
まずはテスト用スライドで確認してください。操作が効かなければ、エラーメッセージと「配置」メニューのスクリーンショットを控えてください。

【権限とデータ】
対象は https://docs.google.com/presentation/* の編集ページのみ。
拡張機能のコードはネットワーク通信、外部送信、Google API、OAuth、外部ライブラリを使用しません。
Chrome Web Storeへの公開はしていません。


v0.2.4: メニュー待機時間の延長、安定確認、古い子メニューの誤選択防止、操作中断、重複DOM要素の除外。実環境未検証。整列は通常2個以上、均等配置は3個以上。
